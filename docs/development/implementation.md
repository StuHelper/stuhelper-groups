# Groups 实施状态

## 当前实现

- 群目录与「我的群」提供公开群卡片、本人申请进度、资格缺项和口令提示。后台配置按修订保存，群号脱敏。口令轮换递增代数，未入群申请者按当前代数重新提交。
- 申请与实际入群分别推进。成员资格变更触发提醒、宽限、恢复或移出。管理员可以延期、豁免和撤销豁免。延期从当前时间和已有期限的较晚者开始。
- 名片模板保存时校验，按原模板单遍渲染。预览返回缺失字段键，使用中性分隔符处理未知性别，按字符数限制结果。
- 规则覆盖关键词、链接、频率和复读。链接协议名忽略大小写。每条消息最多记录一个关键词标签。自动拉黑为永久期限，禁言时长单独配置。
- 批量预览和提交共用成员判定。警告、禁言、解禁和踢出检查当前成员状态，按目标保存结果和跳过原因。同键可重放已经处理的目标，并继续未完成目标。
- 有效留存期内允许受授权查看撤回内容。举报提交及重放检查当前成员关系，模型只接收举报原因与消息正文。处置检查留存、启用的规则、举报状态和当前授权。
- 机器人动作有持久任务和回执，超时后查询实际结果。群级审计分页返回管理结果。目标群禁用机器人、容量不足或权限撤销时，其他目标继续投递。警告成功且后续禁言被拒时保留警告结果。
- 骰子与自助禁言按群启用，支持冷却和保底。自助禁言只作用于本人，结果由机器人回执确认，不写违规记录。管理员可提前解禁。
- 上游资格与 QQ 绑定变更按账号和学校读取当前事实。写事务复核修订与关联群，并原子保存成员状态、去重回执、审计和出站事件。维护端口支持有界清理留存数据、幂等收据、已确认事件及过期频率窗口。

查询使用只读快照事务。写入按作用域以确定顺序加锁，资格事实在写事务外预取，AI 分析在获取写锁前完成并设 5 秒超时。HTTP 与出入站事件可传递 `traceparent`。

## 验证范围

[module.yaml](../../module.yaml) 登记 IQ-02、QQ-01 至 QQ-12、MP-07、BE-01 至 BE-03。仓库检查核对登记的 Go 文件与函数，并使用隔离 PostgreSQL 覆盖角色权限、并发幂等、回滚、过期、撤权、分页和事件顺序。

QQ-10 的本仓测试覆盖撤回内容权限、留存与娱乐动作。菜单位置由客户端和 Koishi 的验收检查。IQ-02 在本仓覆盖账号查询的学校与群范围、字段白名单、排他分页、数据库身份与时间更新。

CI 在 develop、main 的推送和目标分支为两者的 PR 上运行完整模块检查，包含 SDK 生成一致性、仓库与模块规则、文档、Go 格式、vet、竞态测试、构建和工作流检查。
